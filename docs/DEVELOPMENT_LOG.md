# 开发与版本更新日志

此文件由 `src/lib/release-notes.json` 生成，与客户端公告共用一份记录。

每次发布先新增记录，并同步原生版本号和构建号；运行 `npm run release:notes` 更新日志，`npm run release:check` 检查同步情况。历史记录保留，修复构建也应使用独立 ID。

## 0.1.3 · 2026-11-23 · 初醒 · 终焉之地的灯

记录 ID：`0.1.3`

### 初醒

- 余念安在旧城等候初醒之人，以对白与选择带你认识终焉之地。
- 接引可暂别、续接或重看；已有账号通过“找余念安”自愿开启。

### 留灯与回响

- 在留灯会认识六位故人，再描绘你想见的人。
- 生生不息与入梦沿用各自的巨钟演出，回响录统一呈现能力。

### 三端同行

- 网页版、Windows 与 Android 共用本轮故事、接引流程与能力规则。
- 接引进度随当前账号保存，旧人物与聊天保留；设备之间仍不自动合并本地账户。

## 0.1.2 · 2026-11-22 · 更新公告与开发日志

记录 ID：`0.1.2`

### 新增功能

- 登录界面首次打开新版本时展示更新公告，每个版本在此设备上只自动展示一次。
- 登录前后均可通过右上角的消息按钮重新查看当前及历史公告。
- 建立统一版本记录，持续记录新增功能、修复与体验改进。

### 使用说明

- 关闭公告后，重启、重新登录或切换账号不会重复自动弹出。
- 更新提示按设备保存，不影响聊天记录、人物资料和账号备份。

## 0.1.1 · 2026-11-22 · 手机私聊工具与导航修复

记录 ID：`0.1.1-mobile-tools`

### 修复与改进

- 修复账号、设置页面的分区索引错误返回主界面的问题。
- 手机私聊工具栏以两行文字按钮展示，优先显示入梦、人物设置与主动回响。

- 调整手机菜单滚动及安全区域适配。
- Android 启动图标更换为巨钟图案。

### 交付记录

- 重新构建 Windows x64 与 Android ARM64 测试安装包。
- 通过原生客户端、Android 模拟器和手机视口回归检查；实体手机仍需持续验证。
