# 开发与版本更新日志

此文件由 `src/lib/release-notes.json` 生成，与客户端公告共用一份记录。

每次发布先新增记录，并同步原生版本号和构建号；运行 `npm run release:notes` 更新日志，`npm run release:check` 检查同步情况。历史记录保留，修复构建也应使用独立 ID。

## 0.2.0 · 2026-11-25 · 听见 · 免费语音对话

记录 ID：`0.2.0`

### 朗读回复

- 点喇叭即可让角色念出最近的回复。网页版与 Windows 使用免费的 Microsoft Edge 语音，无需 API key。
- Android 使用设备自带的语音引擎，离线也能出声。

### 语音输入

- 点麦克风说话，识别结果追加在已有草稿之后，不会覆盖你写好的内容。
- Chrome 与 Edge 用浏览器内置识别；Android 用系统语音识别，都不经过服务器。

### 更诚实的状态提示

- 语音没能生成、或没有识别出内容时，会明确说明并保留你的文字与草稿，不再显示 0 秒空语音或虚构的转写结果。
- 切换会话或离开页面会放弃进行中的识别，结果不会串到别的对话。

### 录音权限修复

- 修复 Android 首次使用麦克风时授权被拒、无法录音的问题。

## 0.1.3 · 2026-11-23 · 初醒 · 终焉之地的灯

记录 ID：`0.1.3`

### 初醒

- 余念安在旧城等候初醒之人，以对白与选择带你认识终焉之地。
- 接引可暂别、续接或重看；已有账号通过“找余念安”自愿开启。

### 留灯与回响

- 在留灯会认识六位故人，再描绘你想见的人。
- 生生不息与入梦沿用各自的巨钟演出，回响录统一呈现能力。

### 三端同行

- 网页版、Windows 与 Android 共用本轮故事、接引流程与能力规则。
- 接引进度随当前账号保存，旧人物与聊天保留；设备之间仍不自动合并本地账户。
