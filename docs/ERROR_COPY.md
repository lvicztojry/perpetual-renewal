# 错误状态中文文案规范 v0.1

## 目标

错误状态文案要让用户快速知道三件事：

- 发生了什么：用用户能理解的结果描述，不展示内部异常。
- 现在能做什么：给出一个明确下一步，如重试、检查设置、换文件、稍后再试。
- 什么不会暴露：任何错误提示、日志摘要和导出内容都不能包含 API key、Base URL 原文、Authorization header、prompt、请求 payload、供应商 raw payload、数据库连接串、vault 密文、cron secret 或 `.env` 内容。

本规范覆盖聊天、素材导入、语音、模型连接、数据导出、数据库配置缺失、主动回响 cron secret 缺失等第一版常见错误。具体组件可以根据空间压缩文字，但不能删除“发生了什么”和“下一步”。

## 总原则

| 原则 | 要求 | 反例 |
| --- | --- | --- |
| 先说结果 | 先告诉用户当前动作是否失败、暂停或已降级 | `500 ProviderError: Unauthorized` |
| 给下一步 | 每条错误都应指向可执行动作 | `出错了` |
| 不甩锅 | 不把供应商、数据库或浏览器错误原样抛给用户 | `upstream returned raw body...` |
| 不泄密 | 不出现 key、baseUrl、prompt、raw payload、连接串 | `Bearer sk-... 无效` |
| 保持陪伴感 | 聊天和主动回响错误要温和，避免责备用户 | `你太久没回复，发送失败` |
| 可恢复优先 | 能重试、重新生成、重新选择文件或改设置时直接告诉入口 | `失败，请联系管理员` |
| 日常不出戏 | 普通技术错误不主动强调“我是 AI”，除非风险或能力边界需要 | `作为 AI 我无法处理网络错误` |

## 推荐句式

短提示：

- `刚刚没有发送成功，可以再试一次。`
- `现在还不能连接模型，请先在设置里保存 API key。`
- `这个文件暂时不能导入，请换成 .txt、.jsonl 或 .json。`

带下一步：

- `回复生成失败了。你可以点“重新生成”，或去设置里测试模型连接。`
- `导出没有完成。请稍后重试；如果多次失败，先确认当前账号仍处于登录状态。`
- `主动回响调度没有运行，因为缺少 cron secret。请在部署平台配置 PROACTIVE_CRON_SECRET 后再触发。`

## 禁止暴露清单

错误文案、toast、API 响应中的 `message`、前端状态、可下载导出、成本看板和安全事件摘要均不得包含：

- API key、token、Bearer header、JWT、password、secret。
- `LLM_BASE_URL`、用户填写的 Base URL 原文、数据库连接串、Redis 或对象存储连接串。
- system prompt、developer prompt、拼装后的完整 prompt、用户原始安全触发文本。
- 供应商 raw payload、完整 HTTP response body、堆栈、内部路径。
- vault ciphertext、IV、auth tag、加密密钥指纹之外的敏感材料。

允许展示：

- 脱敏 provider：如 `compatible`、`anthropic`、`gemini`。
- 脱敏 model：如用户选择的模型名，除非模型名本身包含密钥形态。
- 错误类型枚举：如 `missing_api_key`、`unauthorized`、`rate_limited`、`network_error`。
- 延迟、是否使用 fallback、是否可重试、下一步入口。

## 场景文案矩阵

| 场景 | 用户可见文案 | 下一步动作 | 禁止暴露 |
| --- | --- | --- | --- |
| 聊天消息发送失败 | `这条消息没有发出去，可以再试一次。` | 保留输入，提供重试 | request body、cookie、内部错误 |
| AI 回复生成失败 | `刚刚没有生成出回复，可以重新生成一次。` | 展示重新生成入口；必要时引导测试模型连接 | prompt、供应商 response、Base URL |
| 真实模型不可用并回退 mock | `当前模型暂时不可用，已先用本地演示回复接住这次对话。` | 引导设置页测试连接 | API key、供应商原始错误 |
| 消息删除失败 | `这条消息暂时删不掉，请稍后再试。` | 保持原状态，允许重试 | record id 以外的内部堆栈 |
| 重新生成失败 | `重新生成没有成功，可以再点一次，或先检查模型连接。` | 重试或设置页测试连接 | prompt、raw payload |
| 素材导入接口失败 | `这批素材没有导入成功，可以稍后再试。` | 保留文本，不清空输入 | 原始异常、脱敏前文本 |
| 导入文件扩展名不支持 | `这个文件暂时不能导入，请换成 .txt、.jsonl 或 .json。` | 重新选择文件 | 本地路径 |
| 导入文件超过 512KB | `文件有点大，第一版单个文件最多支持 512KB。` | 拆分文件后重试 | 文件内容 |
| JSON/JSONL 解析失败 | `文件内容没有解析成功，请检查格式后再导入。` | 定位到 JSON/JSONL 格式说明 | 原始解析堆栈 |
| 导入内容含疑似密钥 | `已自动隐藏疑似密钥片段，再作为候选记忆保存。` | 允许用户检查 pending 记忆 | 密钥原文 |
| 浏览器不支持录音 | `当前浏览器暂时不能录音，可以先用文字输入。` | 回到文字输入 | 浏览器底层异常 |
| 麦克风权限被拒绝 | `没有拿到麦克风权限，可以开启权限后再试，或先用文字输入。` | 引导浏览器权限 | 设备标识 |
| 语音转文字失败 | `这段语音没有识别出来，可以再录一次，或改用文字。` | 重录或文字输入 | 音频内容、供应商 raw payload |
| 语音回复生成失败 | `语音暂时没有生成成功，文字回复还在。` | 保留文字，允许重试朗读 | TTS payload、Base URL |
| 模型连接缺少 key | `还没有可用的 API key，请先在设置里保存。` | 打开/停留在模型设置 | key 字段值 |
| 模型连接鉴权失败 | `模型连接没有通过，请检查 API key 是否可用。` | 重新保存 key 或测试连接 | Authorization header、key 尾部以外信息 |
| 模型名不可用 | `当前模型不可用，请换一个模型后再测试。` | 刷新模型列表或手动修改 | 供应商 raw payload |
| Base URL 不可达 | `连接地址暂时无法访问，请检查地址或网络后再试。` | 检查地址、网络、代理 | Base URL 原文 |
| 模型限流 | `模型服务现在有点忙，可以稍后再试。` | 稍后重试，必要时换模型 | rate limit raw header |
| 数据导出失败 | `导出没有完成，请稍后再试。` | 重试；多次失败检查登录状态 | 导出内部异常、vault 字段 |
| 数据库未配置，本地开发 | `当前没有连接真实数据库，已使用本地演示数据。` | 配置 `DATABASE_URL` 后跑 db smoke | 连接串 |
| 数据库未配置，部署门禁 | `生产环境缺少数据库配置，暂时不能上线。` | 配置 `DATABASE_URL`、运行 migrate/db smoke | 连接串 |
| cron secret 缺失或错误 | `主动回响调度未授权，请检查 cron secret 配置。` | 配置或修正 `PROACTIVE_CRON_SECRET` | secret 原文 |
| 会话过期 | `登录状态已过期，请重新登录后继续。` | 跳转登录 | cookie/session token |
| 通用未知错误 | `刚刚没有完成，可以稍后再试。` | 保留用户输入和页面状态 | 堆栈、内部路径、raw payload |

## API 响应建议

服务端返回错误时优先使用稳定字段，便于前端映射中文文案：

```json
{
  "ok": false,
  "errorType": "missing_api_key",
  "message": "还没有可用的 API key，请先在设置里保存。",
  "retryable": false,
  "nextAction": "open_model_settings"
}
```

字段要求：

- `message` 是可直接展示给用户的中文短句。
- `errorType` 是稳定枚举，不包含密钥、URL、prompt 或供应商原文。
- `retryable` 帮助前端决定是否展示“重试”。
- `nextAction` 用于前端定位按钮，如 `retry`、`regenerate`、`open_model_settings`、`choose_file`、`login_again`。

## QA 检查

人工检查每个错误状态时至少确认：

- 文案能回答“发生了什么”和“下一步做什么”。
- 用户输入、导入文本、聊天草稿不会因为错误被静默清空。
- 聊天和主动回响错误保持温和，不责备、不威胁、不制造愧疚；未回复相关表达使用撒娇式想念。
- 模型连接、语音、导出、数据库和 cron 错误不展示 API key、Base URL 原文、prompt、raw payload、数据库连接串或 secret。
- 开发/部署文案区分本地 fallback 与生产门禁：本地可以演示，生产必须补齐配置。

建议回归命令：

```bash
npm run secrets:check
npm run smoke
npm run e2e
```

M30 本轮只建立文档规范；后续 UI/API 文案调整应以本文件为准。
