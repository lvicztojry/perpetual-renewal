当前状态统一见 [MVP_STATUS.md](MVP_STATUS.md)。本轮按用户确认的「个人主体、无域名服务器、先在微信开发者工具预览并联调」准备，不涉及正式发布或云服务购买。

用户已明确要求保留现有全部功能。原生源码在 `miniprogram/`，现有 10 个页面覆盖账号、人物、私聊、群聊、记忆、入梦、设置、文件导入导出、语音和回响录/故事；前台刷新、可见消息已读、群聊断线恢复复用现有服务端。代码实现和模拟数据检查不等于全部功能已在微信及手机上验收。

全量范围见 `miniprogram/feature-scope.json`，迁移与验收规则见 [WECHAT_FEATURE_PARITY.md](WECHAT_FEATURE_PARITY.md)。清单覆盖当前全部 API 路由及没有接口的动画/故事等能力，自动检查防止后续漏项。现有网页功能均保留，不通过删除功能来适应小程序。

密码、模型 Key 和 Cookie 不主动写入客户端持久存储；会话只在内存中，重载后需登录。用户主动导出的文件、语音播放临时文件按微信文件系统处理。HTTP 仅限自己的可信电脑/局域网试用。发送真实聊天会使用账号模型额度；隔离测试仅调用模拟模型。

## 电脑准备

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，微信扫码登录。
2. 双击根目录 `启动生生不息.bat`。使用原账号登录小程序；小程序内已有注册、验证/找回、人物创建和模型设置。已有网页账号共用原资料。
3. 工具选择「导入项目」，目录选仓库的 `miniprogram`，类型选小程序。填微信后台「开发管理 → 开发设置」里的 AppID（公开标识；不要提供 AppSecret）。不使用云开发。
4. 已改用当前登录微信名下的小程序测试号 `wx39395c20924d8b67`。用户曾提供的 `wx25395612d42be941` 经官方工具查询属于小游戏，不能用于此项目；此前导致模拟器报缺少 `game.json`。测试号不代表正式发布账号。
5. 仅在开发者工具「详情 → 本地设置」勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。共享配置保留校验，工具个人配置不入库；此开发选项不适用于发布版。
6. 点击「编译」。服务地址填 `http://127.0.0.1:3000`，使用已有邮箱和密码登录。按「人物列表 → 人物 → 输入消息 → 发送」验证。

## 手机本地调试

1. 电脑和手机连同一可信 Wi-Fi；用根目录 `局域网启动生生不息.bat` 启动，取得窗口显示的 `http://电脑局域网IP:3000`。
2. 工具使用自己的 AppID。启动脚本会把该地址写进 `miniprogram/utils/local-server.generated.js`（不入库），小程序默认地址由此填充，重新编译即可，无需手填。手机访问 `127.0.0.1` 会指向手机自己；换 Wi-Fi 或重连后地址会变，需重新运行启动脚本再编译。
3. 优先尝试工具「真机调试」，按版本提示开启必要调试设置；普通「预览」不等于开启本地域名豁免。若客户端仍阻止 HTTP/局域网请求，先完成模拟器联调，后续配置 HTTPS 测试环境，不取消服务端认证校验。
4. 防火墙、路由器隔离、VPN 可能阻止连接，先用手机浏览器验证 URL。不要为此关闭防火墙或做公网端口映射。

局域网细节见 [LAN_TRIAL.md](LAN_TRIAL.md)。此客户端只接受数字回环/私有 IPv4 加端口，避免把联调版误用于公网。

## 验证清单

- 模拟器编译无 WXML/JS 报错；错误密码显示错误，正确账号能登录。
- 人物和网页端一致，能读历史；发送一次消息，网页刷新后有同一条用户消息和回复。
- 模型失败或超时保留输入；先刷新确认是否已保存，不自动重发，避免重复消息和额度消耗。
- 返回人物、切换人物、退出和重载后，不展示其他账号历史。
- 退出调用原接口并清除客户端 Cookie；服务端沿用现有 session 到期和密码重置撤销机制。
- 手机真机单独验收；模拟器或 Node 契约检查通过不能替代此项。

验证命令：`npm run mini:prepare` 生成共享解析/故事和音效；`npm run mini:check` 检查生成文件、JS/JSON、官方 WXML/WXSS 编译、事件绑定、包大小及全部 API 范围；`npm run mini:test` 启动隔离 Next mock/memory 服务，验证实际原生页面方法与接口。官方编译器默认使用本机微信工具目录，可用 `WECHAT_COMPILER_ROOT` 指定。实际模拟器测试：先设置 `MINI_QA_STAY_OPEN=1` 运行隔离联调，再运行 `node tests/miniprogram-simulator.mjs`，完成后运行同脚本 `--restore` 恢复工具，再停止隔离服务。脚本会临时模拟仅隔离端口的登录和确认弹窗，必须使用测试数据；不得对真实账号跳过确认。不能据模拟器测试推断麦克风、分享、音频或真机已通过。
