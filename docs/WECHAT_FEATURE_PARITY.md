# 小程序全功能迁移与验收范围

依据用户 2026-11-20 的明确要求：所有现有功能均保留。当前状态统一见 [MVP_STATUS.md](MVP_STATUS.md)，导入操作见 [WECHAT_MINIPROGRAM.md](WECHAT_MINIPROGRAM.md)。

## 交付原则

小程序目标是完整覆盖当前网页的业务功能、数据和可用操作。已新增 10 个原生页面及共享请求、生命周期、录音/播放、文件处理能力；全部功能通过模拟器及真机验收后，才可以称为完整迁移。目前官方模板编译、Node 隔离联调和真实微信模拟器核心流程均已通过；真机设备能力、真实供应商及逐项完整回归仍需独立验收。

不把「去电脑网页操作」作为最终小程序的功能替代。现有网页继续保留，原始数据、用户模型配置、记忆/群聊可见范围和账号隔离规则共用服务端。暂未在网页实现的历史搜索/长期归档等，不因本次迁移被误记为已有能力。

| --- | --- | --- |
| 账号 | 注册、邮箱验证、登录、退出、忘记/重置密码 | 邮件令牌的应用入口和会话恢复；错误密码、过期/复用令牌、账号切换 |
| 个人与设置 | 昵称、时区、语言、回复偏好、全局主动开关、删除账号 | 原校验、删除范围及不可逆操作确认均保留 |

| 记忆 | 候选、确认、生效、纠错、原子替代、归档、遗忘、分页变更历史 | 版本冲突、来源及时间、遗忘范围、导出一致性均保留 |

| 主动回响 | 私/群独立权限、全局开关、频率、安静时段、草稿/发送/忽略、调度 | 后端调度继续运行；小程序挂起不承担调度职责 |
| 模型 | 全部现有供应商、BYOK、加密保存/删除、模型读取、手填、连接测试 | Key 经业务后端保存，不打包；错误和导出不暴露 Key |
| 语音 | 录音、停止/取消、转写、TTS、播放/停止、语言处理 | `wx.getRecorderManager`、文件上传与音频上下文；权限拒绝、中断和格式兼容真机测试 |
| 数据 | 一致导出、群导出、用量统计、账号级联删除 | 文件保存/打开/分享按微信文件系统实现，不仅展示 JSON |

机器可读清单：`miniprogram/feature-scope.json`。`implemented-awaiting-manual-wechat-validation` 表示已有代码，尚未完成微信验收。测试将当前 API 目录和清单比对，新增未登记 API 会失败；这只能检测接口漏项，UI 子功能还必须按本表实际验收。

## 平台差异的处理

- 前台自动刷新映射为 `App.onShow/onHide`、`Page.onShow/onHide` 管理的请求和轮询，不能停留在手动刷新作为最终实现。
- 服务端主动生成与微信系统通知分开验收：保留站内主动消息、未读和后台生成；微信外部通知须符合授权、模板和类目条件，不能承诺任意内容无限推送。没有可用通知资格时明确记录为平台阻塞，不标为已完成。
- 小程序挂起后不保证常驻 JS/音频。后台调度由电脑服务或之后的线上服务负责；PWA 的 Service Worker/安装机制由小程序宿主承担，对应体验需要另验。
- 录音、文件和音效等权限/设备能力不能用 Node 检查或浏览器截图替代真机验收。
- 个人主体限制正式公开发布 AI 深度合成类功能；本地开发可以准备代码，但不能承诺个人主体能保留全部 AI 功能通过上线审核，也不采用隐藏功能或错误类目规避审核。

## 施工与验证顺序

1. 接入和页面代码：已写入账号、人物、私聊、群聊、记忆、入梦、设置、文件、语音及演出页面。
2. 官方编译器：全部 WXML/WXSS 已通过；生成文件、事件绑定和包体检查已通过。
3. 隔离接口联调：已通过人物、私聊/重生成、记忆、入梦、群聊恢复、共同记忆、资料/凭据、导出、记录提炼及账号隔离。
4. 实际微信端：2026-11-21 用户重新授权后，正确小程序测试号上的登录、Cookie/HTTP、私聊和群聊发送、记忆建立、入梦生成、设置读取、本地解析/提炼和故事/动画控制通过。截图已人工检查，修复 JSON require 与按钮宽度问题。测试拦截与会话已清理，恢复正常登录入口，最终 error 日志为空。真机麦克风/播放/分享和真实模型仍待独立验收。
5. 对照本表逐项做模拟器和手机验收，验证同账号网页互通、异账号隔离、失败恢复；公开发布另行满足主体和服务资质。

完成证据必须逐项注明日期、运行环境与测试范围。已有网页验收不自动成为小程序验收，接入原接口也不等于对应原生 UI 已完成。
