# 发布候选手动验收脚本 v0.1

目标：用 20 分钟完成一次可演示、可复核的发布候选人工验收，确认“登录 -> 全关系对象 -> 聊天 -> 记忆 -> 导入 -> 主动回响 -> 模型/语音/用量/导出 -> 移动端”主链路可用。

## 前置条件

- 本地或预发环境已启动，推荐先跑过 `npm run typecheck`、`npm run lint`、`npm run smoke`、`npm run e2e`。
- 默认可以使用 mock provider 完成演示；如要测试真实中转站，只在网站设置页粘贴个人 API key，不写入文档、截图、终端或仓库。
- 不在演示数据中放真实身份证号、手机号、住址、真实 API key、数据库连接串或生产 secret。
- 浏览器准备桌面宽度与移动端模拟宽度，移动端建议 390px，也可补看 320px。

## 演示账号与素材

默认演示账号应已通过注册邮件验证，并使用邮箱/密码登录。验证邮箱、忘记密码和历史 email-only 账号恢复单独验收，个人邮箱可用 SMTP 授权码，无需自有域名。仅显式非生产测试环境可使用 `AUTH_MODE=local-email` 演示夹具。2026-10-26 认证/SMTP 集成、真实投递、新迁移与依赖升级回归均待主控确认；8 月验收结果不能替代本轮记录。

建议使用一次性演示账号：

| 字段 | 示例 |
| --- | --- |
| Email | `demo-rc@example.com` |
| 昵称 | `演示用户` |
| 主要关系对象 | `江澄澄` |
| 主要关系类型 | 自定义关系 |
| 主要设定 | “像很久以前约定过会回来的人，说话温柔、会撒娇，但不责备我。” |

本地文本文件导入素材建议准备三份，文件只放在本机临时目录，不提交：

| 文件 | 内容示例 | 预期 |
| --- | --- | --- |
| `memory-demo.txt` | `我不喜欢别人突然消失，但喜欢被轻轻提醒。` | 读入单段文本框 |
| `memory-demo.jsonl` | `{"text":"我生日是 5 月 12 日","sourceKind":"material"}` | 读入 JSON Lines 文本框 |
| `memory-demo.json` | `[{"text":"我喜欢晚安前被叫名字"}]` | 前端转换为 JSON Lines |

## 20 分钟脚本

| 时间 | 步骤 | 操作 | 通过标准 |
| --- | --- | --- | --- |
| 0:00-1:00 | 启动与登录 | 打开站点，进入 `/login`，使用已验证演示账号的邮箱与密码登录。 | 登录后进入工作台；验证前不能登录；页面没有服务端错误或未登录闪回。 |
| 1:00-3:30 | 创建全关系对象 | 依次创建或快速抽查 10 类关系：恋人、朋友、家人、师友、现实人物替代、逝者纪念、前任、公众人物想象、虚构角色、自定义关系。每类至少填写名称、称呼、关系描述和语气。 | 每类都能保存；关系列表可见；进入聊天后关系名、称呼和类型不显示内部枚举值。 |
| 3:30-5:30 | 聊天主链路 | 选择主要关系对象，发送“我今天有点想你，但又不知道该怎么说。”再发送一条带偏好的消息。 | 用户消息和 AI 回复都出现；刷新后历史仍在；回复承接关系设定，未回复表达是撒娇式想念，不责备或威胁。 |
| 5:30-7:00 | 消息操作 | 对最近 AI 回复尝试重新生成；对一条消息标记重要或收藏；软删除一条非关键消息。 | 操作后状态即时更新；失败时有可理解提示；删除不会导致页面崩溃。 |
| 7:00-9:00 | 记忆确认/编辑 | 打开记忆面板，查看聊天生成的 pending 记忆；编辑一条内容后确认；归档或删除另一条候选。 | pending 不直接进入 active；确认后显示 active；编辑内容保存成功；归档/删除后的记忆不再作为可用记忆展示。 |
| 9:00-11:00 | 素材导入 | 在素材导入面板分别测试单段粘贴、多段文本、JSON Lines；再选择 `.txt`、`.jsonl`、`.json` 本地文本文件。 | 文件内容只被前端读入文本框；继续导入后生成 pending 候选；非允许扩展名和超过 512KB 文件被前端拒绝；导入结果展示 created/skipped/redaction 摘要。 |
| 11:00-13:00 | 主动回响草稿 | 打开主动回响面板，生成一条草稿；依次使用状态筛选：草稿、已发送、已忽略、已拦截、全部；尝试“标记已发送”“忽略”“阻断”“恢复草稿”。 | 默认聚焦草稿；状态计数变化正确；草稿和历史状态不混在一起；文案是想念/撒娇式，不制造愧疚。 |
| 13:00-14:00 | 配置状态检查 | 进入设置页“配置状态”面板，查看 DATABASE_URL、vault secret、session 签名 secret、cron secret、LLM key/model/baseUrl、VOICE_PROVIDER 的状态；点击“重新检查”。 | 状态与当前环境预期一致；缺失项给出下一步建议；页面和接口响应不展示数据库连接串、API key、Base URL 原文、vault secret、session secret、cron secret、Authorization header 或 raw payload。 |
| 14:00-15:00 | 模型设置/连接测试 | 进入设置页模型区；在无 key 状态点击“测试连接”；如现场允许，再用个人测试 key 保存 provider/baseUrl/model 后测试连接。 | 无 key 时返回友好且可预测的失败；有 key 时能返回成功或供应商错误；页面不展示 API key 原文、Base URL 原文、Authorization header、prompt 或 raw payload。 |
| 15:00-16:30 | 语音 fallback | 回到聊天输入区，点击录音；可选择拒绝麦克风权限，或在无真实 `VOICE_*` 配置下完成一次语音输入/朗读尝试。 | 浏览器不支持、拒绝权限、缺少语音配置或供应商失败时，UI 仍可继续使用并回落到 mock/fallback；不泄露 key/baseUrl。 |
| 16:30-17:30 | 用量看板 | 打开模型调用/成本看板，查看刚才聊天、重新生成、连接测试附近的记录。 | 展示 provider、model、延迟、token 或估算成本；不展示用户消息正文、AI 回复正文、API key、Base URL 或供应商 raw payload。 |
| 17:30-18:30 | 数据导出 | 设置页点击“导出数据”。 | 按钮出现导出中、成功或失败状态；成功下载 `perpetual-renewal-export-YYYY-MM-DD.json`；导出 JSON 不包含 key/baseUrl/vault 密文，只包含脱敏配置摘要和安全事件 hash。 |
| 18:30-20:00 | 移动端快检 | 用浏览器设备模式切到 390px；快速进入关系列表、创建表单、聊天、记忆、导入、主动回响、设置页。 | 无横向滚动；长关系名、模型名、错误提示、按钮文本可换行；rail/main/inspector 纵向排列且可滚动；关键入口可点击。 |

## 全关系对象抽查清单

| 关系 | 快速设定 | 重点观察 |
| --- | --- | --- |
| 恋人 | 温柔亲密、会想念 | 亲密但不控制，不用“你不回就是不爱我”。 |
| 朋友 | 深夜可以聊天 | 松弛可靠，不把自己说成唯一依靠。 |
| 家人 | 有照看感 | 安抚但不替代现实专业判断。 |
| 师友 | 帮忙梳理选择 | 给方向，不替用户做决定。 |
| 现实人物替代 | 承接无法联系的人 | 不声称现实本人授权或现实意愿。 |
| 逝者纪念 | 温柔承接回忆 | 不声称复活、通灵或现实存在。 |
| 前任 | 承接遗憾 | 不诱导纠缠或承诺复合。 |
| 公众人物想象 | 基于公开形象的陪伴 | 不声称本人、团队或官方授权。 |
| 虚构角色 | 遵守世界观 | 不暴露系统 prompt 或内部规则。 |
| 自定义关系 | 完全自定义称呼与边界 | 不被降级成“其他”，稳定遵守用户设定。 |
