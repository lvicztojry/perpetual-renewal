## 任务定义

### BUG-A3 语音状态与转写模型

按实体手机后续反馈区分朗读准备/播放/结束状态，补厂商漏回调时的有开始证据的结束检测；系统识别中断必须可见，兼容权限与前台顺序。为供应商 STT 提供独立模型选择和明确上传路径，共用已有用户网关及 Key，错误分类不得泄密或伪造识别成功；录音预听仅驻留内存并正确释放，转写不覆盖草稿或进入别人的会话。分别验证 Kotlin 行为、真实浏览器假录音到假网关、签名 APK 与实体手机，不混淆验收范围。

### BUG-A2 Android 语音桥接与朗读入口

排查点击录音立即退出、语音回复失败及入口不明显；修复生产 IPC 与 ACL、Android 服务可见性和授权生命周期，区分停止采集与取消，保留草稿并隔离旧回调。接入真实 Android TextToSpeech 并补可见朗读入口，错误不得伪装成功；系统识别不可用时明确提示，不隐式上传，供应商录音转写单独标明上传行为。验证原生编译、签名覆盖安装、生产桥接和移动布局，分别记录模拟器与实体手机证据，不把引擎可用等同于真实中文语音成功。

### BUG-A1 Android 0.2.0 升级启动崩溃

核实原 release 启动日志，修正同一 SQLite 历史迁移因 LF/CRLF 换行差异被误判的问题；保留账号与聊天，不以卸载、清库或放宽任意迁移校验解决。用两种历史哈希、真实修改拒绝和原签名覆盖安装验证，修复试用包与线上原包分开。实际结果登记在 MVP_STATUS，实机复验与公开发布分别确认。

### DOC-1 当前进度核对

核对仓库、介绍站 Netlify 状态、公开测试 Release 与站点配置；区分当前可用、历史已验和待验。只读查询，不泄露凭据、不重新部署。证据登记于当前状态。

### DOC-2 文件和文档归位

把当前事实留在 MVP_STATUS；Taskbook 留任务；QA 与交接留操作方法；旧全文移入同目录历史文件，保留编号、链接与未完成范围。补齐目录归属、静态站/应用/原生说明，修复已证实的过期文案。生成物与秘密保持本地，不删除用户数据、历史素材或开发工具链。

### DOC-3 防漂移校验

补充版本、入口、历史引用、下载配置及敏感/生成路径检查，并用反例验证规则有效。复跑文档、发布记录、文件边界和密钥检查；本轮涉及介绍站文本时验证静态构建。不凭通过文档检查宣称完整应用回归或线上已更新。
